Installation guide

From download to desktop.

Follow these steps to prepare and boot NoahOS.

01

Download the files

Download both ISO parts and the SHA256SUMS.txt file above. Keep them together in one folder.

02

Rebuild the ISO

On Windows, open Command Prompt in the download folder and run:

copy /b noahos-2026.11.08-x86_64.iso.part-00+noahos-2026.11.08-x86_64.iso.part-01 noahos-2026.11.08-x86_64.iso

On Linux, run:

cat noahos-2026.11.08-x86_64.iso.part-* > noahos-2026.11.08-x86_64.iso
03

Verify the image

On Linux, run:

sha256sum -c SHA256SUMS.txt

On Windows PowerShell, run:

Get-FileHash .\noahos-2026.11.08-x86_64.iso -Algorithm SHA256

Compare the result with this expected SHA256:

cf7d0a4181642cb8d4f4db1e25a0e0db4659f1cc26f88f6a744c77ac1a6d8f63
04

Create a bootable USB

Use Rufus on Windows or KDE ISO Image Writer on Linux to write the reconstructed ISO to a USB drive.

Important: Writing the image erases the selected USB drive. Double-check the target before starting.

05

Boot NoahOS

Restart your computer, open its boot menu, and select the USB drive. Choose the NoahOS boot option to start the live environment.

Before you begin

NoahOS 0.1.0 is a pre-release intended for testing. Back up important data and test the live environment before considering installation.
