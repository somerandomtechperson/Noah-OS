Installation guide

From download to desktop.

Follow these steps to prepare and boot NoahOS.

01

Download the files

Download both ISO parts and the noahos-2026.11.12-x86_64.iso.sha256 file above. Keep them together in one folder.

02

Rebuild the ISO

On Windows, open Command Prompt in the download folder and run:

copy /b noahos-2026.11.12-x86_64.iso.part.01+noahos-2026.11.12-x86_64.iso.part.02 noahos-2026.11.12-x86_64.iso

On Linux, run:

cat noahos-2026.11.12-x86_64.iso.part.* > noahos-2026.11.12-x86_64.iso
03

Verify the image

On Linux, run:

sha256sum -c noahos-2026.11.12-x86_64.iso.sha256

On Windows PowerShell, run:

Get-FileHash .\noahos-2026.11.12-x86_64.iso -Algorithm SHA256

Compare the result with this expected SHA256:

01695f80ef78d31541fd0c60f58394137a386266281ea7f68118946c94b81b0c
04

Create a bootable USB

Use Rufus on Windows or KDE ISO Image Writer on Linux to write the reconstructed ISO to a USB drive.

Important: Writing the image erases the selected USB drive. Double-check the target before starting.

05

Boot NoahOS

Restart your computer, open its boot menu, and select the USB drive. Choose the NoahOS boot option to start the live environment.

Before you begin

NoahOS 2026.11.12 is a development pre-release. The update checker is an early prototype and does not yet install system updates. Back up important data and test the live environment before considering installation.
