# Contributing to NoahOS

Thanks for your interest in contributing to NoahOS!

Contributions, suggestions, bug reports, and improvements are welcome.

## Reporting Bugs

If you find a bug:

1. Check whether it has already been reported.
2. Open a GitHub Issue.
3. Include a clear description of the problem.
4. Include steps to reproduce it.
5. Mention your hardware and relevant system information.

## Suggesting Features

Feature suggestions are welcome.

Please open a GitHub Issue explaining:

- What you would like to see added.
- Why it would be useful.
- How you think it could improve NoahOS.

## Submitting Changes

To contribute code or configuration changes:

1. Fork the repository.
2. Create a branch for your changes.
3. Make and test your changes.
4. Commit your work with a descriptive commit message.
5. Open a Pull Request explaining what you changed.

## Development Guidelines

- Keep changes focused and organized.
- Test changes before submitting them.
- Avoid unnecessary modifications to existing functionality.
- Preserve third-party license files and notices.
- Document significant changes when appropriate.

## Questions

For questions or general discussion, open a GitHub Issue.

Thank you for helping improve NoahOS!
