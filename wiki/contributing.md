# Contributing

Contributions, suggestions, bug reports, and documentation improvements are welcome.

## Report a bug

Before opening an issue, check whether it has already been reported. Then use the [GitHub issue tracker](https://github.com/somerandomtechperson/Noah-OS/issues) and include:

- A concise title and description.
- The NoahOS build ID or release.
- Steps to reproduce the problem.
- Expected and actual behavior.
- Hardware details and whether the issue occurs on real hardware or in a virtual machine.
- Relevant logs or error messages, with personal information removed.

## Suggest a feature

Open an issue explaining the proposed change, the problem it solves, and any relevant context.

## Submit code

1. Fork the repository.
2. Create a branch for your work.
3. Keep changes focused.
4. Test the changes where practical.
5. Update documentation when behavior changes.
6. Open a pull request describing the change and its testing.

See the repository's [CONTRIBUTING.md](../CONTRIBUTING.md) for the project contribution guidelines.

## Be careful with sensitive information

Never include passwords, tokens, private keys, personal documents, or unredacted network details in public issues, commits, screenshots, or logs.
