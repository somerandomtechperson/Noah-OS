# Desktop and applications

NoahOS uses KDE Plasma as its desktop environment and applies project-specific visual and configuration changes.

## Desktop environment

KDE Plasma provides the desktop shell, panels, application launcher, system tray, window management, and system settings. NoahOS customizes the experience with its own branding, wallpaper, and desktop defaults.

## Applications

The exact application set can change as the ISO profile evolves. The applications visible in a particular build are the authoritative list for that build. NoahOS is based on Arch Linux, so software availability is also shaped by the upstream Arch package ecosystem.

## System settings

Use KDE System Settings for desktop and hardware preferences exposed by Plasma. Some options may be unavailable or behave differently in the live environment.
