# About NoahOS

NoahOS is a personal Linux distribution project built on Arch Linux and centered on KDE Plasma. Its goal is to provide a cohesive desktop experience with custom branding, sensible defaults, and a bootable live environment.

## At a glance

| Area | Current direction |
| --- | --- |
| Base system | Arch Linux |
| Build system | Archiso |
| Desktop | KDE Plasma |
| Architecture | x86_64 |
| Boot modes | UEFI and legacy BIOS in the current profile |
| Distribution model | Rolling development |
| Project status | Experimental; actively developed |

## What makes up NoahOS?

- **Base system:** Arch Linux provides the underlying packages and system tools.
- **Desktop:** KDE Plasma supplies the desktop shell and settings environment.
- **Project customization:** NoahOS adds its own branding, desktop defaults, wallpaper, and system configuration.
- **Live image:** The ISO is built with Archiso and can be started without installing the operating system.

## Current status

NoahOS has booted on physical hardware and has also been tested in virtual machines. The project remains under development. Hardware compatibility, installation support, update workflows, and desktop behavior may vary by build.

A graphical installer is not documented as available in the current project state. Treat NoahOS as a live development environment unless a release explicitly provides an installer.
