# NoahOS Wiki

Welcome to the NoahOS project wiki. This is the central reference for using, understanding, and contributing to NoahOS.

> **Project status:** NoahOS is an experimental, Arch Linux-based distribution in active development. Documentation describes the repository and known project behavior; interfaces and procedures may change between builds.

## Wiki

- [About NoahOS](about.md) — project goals, architecture, and current status.
- [Getting started](getting-started.md) — download, verify, and prepare a live USB.
- [Live environment](live-environment.md) — booting and using the current live system.
- [Desktop and applications](desktop.md) — KDE Plasma, customization, and included software.
- [Updates](updates.md) — the package update checker and planned update experience.
- [Troubleshooting](troubleshooting.md) — common boot, download, and live-session problems.
- [Building NoahOS](building.md) — developer build prerequisites and workflow.
- [Contributing](contributing.md) — bug reports, suggestions, and code contributions.

## Documentation principles

NoahOS is under active development. A feature described as planned or in development should not be assumed to be available in a released ISO. When instructions differ between builds, use the release notes and documentation shipped with the build you downloaded.
